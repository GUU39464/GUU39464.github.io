项目概览

适配不同客户，
保持各自的品牌识别。

实习中，我为多个行业客户制作营销图与视频封面：根据产品卖点选择场景和信息层级，再将重复的制作要求整理为 Skill。以下分别展示系列适配、素材到成图的判断与工作流程。

01 / 系列与适配

延续品牌，变化内容。

六个行业客户，十八张系列作品。保留各自的品牌线索，再根据产品、使用场景和传播重点调整画面与信息层级。

植物原料 / 系列适配

以原料差异，组织同系列封面。

植物原料外观不同，封面需要让人辨认原料与粉末的关系。以自然环境承托主体，再用相近的标题与品牌区域连接系列。

保持统一
深绿与金色 / 衬线标题 / 原料与粉末组合
按需变化
原料形态 / 生长环境 / 光线与构图

焊接设备 / 系列适配

围绕产品卖点，调整信息重心。

面罩、焊机和焊材包装需要不同的展示尺度。分别突出产品状态、应用场景与核心卖点，以黑黄对比和粗体标题保持系列识别。

保持统一
黑黄对比 / 强标题 / 清晰产品主体
按需变化
产品尺度 / 功能重点 / 应用场景

针织帽饰 / 系列适配

把制造与服务信息，转化为图解。

制造过程和服务差异不易通过单一产品照说明，因此使用步骤、对照和产品组合组织信息，让阅读顺序对应表达重点。

保持统一
米白与深绿 / 留白 / 信息模块
按需变化
流程图解 / 产品组合 / 对比关系

功能面料 / 系列适配

同时呈现材料纹理与穿着用途。

面料营销需要兼顾细节与应用。将纹理近景与穿着场景结合，并突出型号和功能文字，帮助读者建立材料与用途的联系。

保持统一
品牌蓝 / 面料近景 / 型号信息
按需变化
穿着场景 / 材料纹理 / 内容密度

电动出行 / 系列适配

让车型与主题各有展示重点。

围绕不同车型切换户外、制造与城市场景，用车型标题和产品主体建立阅读重点，延续品牌标与功能信息的组织方式。

保持统一
品牌标 / 车型标题 / 功能模块
按需变化
车型 / 场景 / 信息重点

汽车零部件 / 系列适配

用产品近景，突出结构与材质。

零部件体积小、结构细节多，因此放大产品主体，以金属质感和背景语境表达产品特点，黑绿对比与相近标题层级连接系列。

保持统一
黑绿对比 / 斜体标题 / 金属质感
按需变化
产品结构 / 主体角度 / 使用语境

02 / 产品与场景

让产品进入合适的场景。

03 / 批量与方法

把重复要求，写成流程。

01

拆解任务

明确客户、产品、卖点与内容要求，区分不同产品线。

02

准备素材

选择客户产品图、历史视觉和场景依据，建立输入约束。

03

生成与质检

调用 Skill 制作，检查产品、文字、品牌与构图，再人工修正。

04

归档与交付

记录版本与任务状态，完成审核、输出和资料归档。

04 / 明克任务实证

一次任务，如何被组织。

以明克的多产品任务为例：从历史视觉中提取线索，把产品与版式要求写入任务计划，再对照实际成图。

01 / 制作过程

保留识别，切换产品语境。

延续标题、强调色和工业视觉语气，随产品变化调整主体、使用场景与型号信息。

02 / 制作过程

先分清任务，再安排制作。

两条任务分别记录型号、参数、场景与画面要求。这里是任务规划；当前对应成图展示 MK109。

03 / 制作过程

把设计要求变成可执行约束。

分别限定产品结构、使用场景、信息层级和准确文案。保留必要的人工判断与检查。

04 / 制作过程

从要求，到一张可交付的画面。

任务计划与实际成图并列展示，说明制作依据与输出之间的联系。
