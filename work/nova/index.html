02 / NOVA · PERSONAL CONCEPT PROJECT
视觉规则传播适配动态表达应用样机
01 / Challenge

内容越来越多，
如何保持品牌识别？

NOVA 是面向 AI 内容创作场景的个人品牌概念项目。设计目标是为不同主题与渠道建立共同的视觉规则，让内容变化时仍能识别同一品牌。

02 / Approach

先定义规则，
再展开视觉。

将 Seed、Build、Matrix 转化为图形与模块关系，用统一的字体、色彩和网格组织标识及版面，为后续传播建立基础。

03 / Campaign

更换传播主题，
保留识别线索。

围绕三种主视觉展开系列海报，在不同画幅中调整信息位置和图形比例，同时保留字体、编号与模块关系。

04 / Motion

让图形规则，
成为动态节奏。

将 Seed → Build → Matrix 的图形变化编排为四秒视觉循环，让静态识别延续到动态展示。

NOVA / Motion loop04 sec · Seamless
05 / Execution

从版面规则，
延展到应用样机。

通过车身广告、数字界面与印刷物料样机，展示品牌在不同尺度和载体上的应用设想；这些画面属于概念展示。
